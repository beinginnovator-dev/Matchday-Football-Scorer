# Matchday Football Scorer PWA

A small installable Progressive Web App demo.

## Deploy on Cloudflare Pages
1. Extract this ZIP.
2. In Cloudflare Pages, create a project and upload the extracted folder (Direct Upload), or connect a GitHub repository containing these files.
3. No build command is required. Set the output directory to `/` or the project root.
4. Open the deployed HTTPS URL in Chrome on Android.
5. Use Chrome menu → **Install app** or **Add to Home screen**.

The app is a local demo: it does not use a football API, cloud database, multi-device sync, or real-time clock. Match events and stats are held in the page while it is open.
